# LAST CALL — Арт-байбл

Вид и звук игры. Тон и столпы: [PHILOSOPHY.ru.md](PHILOSOPHY.ru.md); системы, которым служит арт: [GAME-DESIGN.ru.md](GAME-DESIGN.ru.md).

**Одной строкой:** *Реализм с элементами нуара — неоновый свет, дождь за окном, дым сигарет.* Бар — тёплый и грязный; город снаружи — холодный и мокрый.

## 1. Референсная рамка

| Слой | Референс | Что берём |
| :--- | :--- | :--- |
| Интерьеры | Старые бары, интерьеры *Blade Runner 2049*, настроение *Disco Elysium* (не стиль) | Янтарный практический свет, длинные тени, дым в лучах |
| Экстерьер | Мокрый асфальт, отражения неона в лужах | Мокрый асфальт как зеркало, холодный циан/маджента против тёплого интерьера |
| Персонажи | Земные, обычные лица; никто не супермодель | Сначала читаемость силуэта, потом детали |
| UI | Барное оборудование: меловые доски, чеки, подставки, страницы книги | Диегетично, монохром + один акцент |

Явно не то: киберпанковый хром, мультяшная стилизация, хоррор-кровь (PHILOSOPHY §3.5).

## 2. Настройка рендеринга (UE 5.8)

По [docs/LANGUAGES.ru.md](LANGUAGES.ru.md) §8:

- Lumen GI, **Lumen Lite** на тяжёлых сценах; аппаратный Lumen, где он окупается.
- **MegaLights** для множества практических источников бара (лампы, неон, свечение ТВ).
- Nanite везде для геометрии; Virtual Shadow Maps.
- **Локальный объёмный туман** — слой дыма/сигарет, всегда включён в помещении.
- Материалы Substrate под мокрые поверхности; апскейлинг TSR/DLSS/FSR; PSO precaching включён.
- Цель: 60 fps @ 1440p на средней видеокарте (PHILOSOPHY §8); рейтрейсинг опционален.

## 3. Освещение: три настроения

У каждого пространства ровно одно доминирующее настроение за раз; фазовый менеджер их переключает.

| Настроение | Палитра | Где |
| :--- | :--- | :--- |
| **Дневная смена** | Янтарь #E8A24A, пыльные бирюзовые тени, лучи дневного света через жалюзи | Утренняя подготовка, офисная толпа |
| **Ночная смена** | Неоновый маджента #FF3D7F + циан #33E0FF, натриевый оранжевый уличный подмес, жёсткие лужи света | Вечерний пик, час группировок |
| **Опасность** | Один жёсткий источник, глубокие чёрные, один красный практический (вывеска «выход», стоп-сигнал в окно) | Всплески угрозы, обыски, ночные миссии |

Правила:

1. **Каждый источник света мотивирован** — лампа, вывеска, окно. Никакого парящего филла.
2. **Барная стойка всегда самый яркий объект в кадре** — взгляд обязан ложиться туда первым во время смены.
3. **Неоновая вывеска — лицо бара.** Она мерцает при падении репутации фракций; сломана в состоянии забегаловки и чиста в VIP.
4. **Свет полиции** (мигающий синий/красный в окно) — зарезервированный сюжетный свет: только обыски и ночные события, поэтому он всегда что-то значит.

## 4. Материалы

| Поверхность | Рецепт |
| :--- | --- |
| Мокрый асфальт | Низкая шероховатость + маски луж + отражение неона; анимированные ряби капель |
| Дерево стойки | Десятилетия полировки: слоистая шероховатость, круги от стаканов, износ кромок — никогда ровно |
| Стекло | Преломление + тонировка поглощения на жидкость, слой конденсата у края, отпечатки |
| Жидкость | Послойные цвет/непрозрачность/пена; сахарная плотность меняет то, как она липнет |
| Дым | Объёмный, освещённый практическими источниками; сигаретный дым тоньше тумана |
| Латунь/хром | Патина в углублениях, высокий блеск на точках касания (ручки крана, сифон) |

## 5. Инвентарь VFX (минимум для v1.0)

Лента налива (меболл) · частицы брызг · переполнение + декаль · всплеск пены · лёгкая искра от звона бокала · объёмы дыма/сигарет · штора дождя + брызги в лужах · мерцание неона · разбитая бутылка (осколки + мокрый декаль) · мигалка полиции · пыль в лучах · дыхание в холодной ночной воздухе.

## 6. Принципы анимации

- **Сначала вес:** в бутылке жидкость — налив движением бёдер и плеч, а не запястьем (кроме Флейринга, который сознательно театрален).
- **Хореография обслуживания:** налить → подать → протереть стойку; этот идл-луп — сердцебиение игры.
- **Приметы читаются с 3 метров:** смена позы, хват бокала, ориентация головы — анимационный набор угрозы должен читаться без UI (PHILOSOPHY §7).
- **Бой — уродливый и короткий:** максимум два такта, потом развод.
- Лица: MetaHuman или аналог для 3 главных; качества захвата движения не требуется, но зрительный контакт в диалоге обязателен.

## 7. UI / HUD

- Сначала диегетика: меловая доска меню, бумажные блокноты заказов, тетрадь дяди (книга рецептов/журнал заданий), стенная книга на деньги.
- Шкалы (терпение, настроение) — **тонкие подчёркивания под табличкой имени клиента**, а не плавающие бары.
- Угроза никогда не число: это то, как зал замолкает.
- Цвет: тёплая бумага #E7DCC6, чернила #1A1614, по одному акценту на фракцию.
- Шрифт: узкий гротеск для вывесок, моноширинный для книг; оба языка (EN/RU) проверены в UI-размере — кириллица не должна падать в подменный шрифт (задокументированный фейл: шрифт RU всегда в комплекте).

## 8. Звуковое направление

| Слой | Дизайн |
| :--- | :--- |
| Подложки | Приглушённый джаз (контрабас, щётки) → кроссфейд в напряжённый дрон, когда заходит «плохой парень»; *отсутствие* музыки — подсказка |
| Фоли бара | Скрип стульев, звон стекла, налив и шипение, касса, лёд — каждое это награда или предупреждение |
| Город | Дождь по окнам, далёкая сирена, гул трафика — всегда присутствует, громче ночью |
| Правило микса | Во время истории клиента: приглушить всё, кроме голоса + налива; во время опасности: приглушить музыку, оставить фоли резким |
| Права на музыку | Собственные джазовые/нуарные пьесы (библиотеки — запасной вариант; проверять лицензию в духе [FREE-3D-MODELS.ru.md](FREE-3D-MODELS.ru.md): известная лицензия, записано) |
