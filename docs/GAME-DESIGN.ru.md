# LAST CALL — Гейм-дизайн-документ (GDD)
**[English version of this file →](GAME-DESIGN.md)**

Авторитетный дизайн-документ. При конфликте с [PHILOSOPHY.ru.md](../PHILOSOPHY.ru.md) побеждает философия; детали реализации — в [ARCHITECTURE.ru.md](../ARCHITECTURE.ru.md).

**Жанр:** сюжетный симулятор управления с элементами экшена и RPG · **Платформа:** PC · **Камера:** гибрид 1/3-го лица за стойкой, через плечо ночью · **Игроки:** 1, кооп 2–4 · **Сессия:** один игровой день (30–60 мин), фазы в конце дня можно пропустить.

## 1. Основной цикл

```
 ┌─ УТРО: закупка, улучшения, крафт ───────────┐
 │                                              │
 ▼                                              │
 СМЕНА: наливать • слушать • читать зал         │
 │                                              │
 ▼                                              │
 НОЧЬ: доставить • выбить • расследовать        │
 │                                              │
 ▼                                              │
 ИТОГ: чаевые, опыт, репутация фракций, «шум» ──┘
```

Настоящий ресурс игрока — **внимание**; деньги и опыт — его побочные продукты. Каждая фаза тратит его по-своему: экономика утром, люди вечером, опасность ночью.

## 2. Фаза 1 — Подготовка (утро)

| Система | Дизайн |
| :--- | :--- |
| Закупка | Поставщики с лимитами и дрейфом цен; дешёвый алкоголь повышает ночной риск (худшие клиенты), премиум — маржу. Лёд кончается, если забыли. |
| Улучшения | Ремонт кранов, миксер, VIP-зона, свет, музыкальный автомат → каждое открывает механику или сегмент клиентов, каждое видно в баре. |
| Крафт | Настойки/сиропы: ингредиенты, время, крепость. Результат — новые строки рецептов. Провалы пригодны (не тот напиток, смешной эффект) или списываемы. |
| Прогноз репутации | Показывается ожидаемая толпа дня (офис, бандитская ночь, день детектива) — подготовка становится ставкой на то, кто придёт. |
| Таймер | По умолчанию расслабленный; тумблер «спешка» для тех, кто хочет давление. Утро никогда не блокирует день. |

## 3. Фаза 2 — Смена (день/вечер)

### 3.1 Наливание (ключевая механика)

- **Управление:** аналоговый наклон — стик геймпада или протяжка мышью. Наклон задаёт расход; струя — симулированная лента; стакан наполняется слоями.
- **Навыки, которые она проверяет:** твёрдость руки (держать струю в стакане), тайминг (остановиться на риске), знание (верный напиток под заказ), скорость (терпение тает).
- **Провалы:** перелив (потеря, дешёвый напиток), пролит (декаль, реакция клиента), не тот напиток (перелив, удар по терпению), медленно (скука → падение настроения).
- **«Коктейль-Комбо»:** правильная последовательность + окна скорости + непрерывность = *критический успех*: бафф настроения клиенту, бонус чаевых и опыта. Комбо находятся экспериментом и пишутся в книгу рецептов.
- **Флейринг:** открываемый навык — жонглирование и броски, ускоряющие подачу и поднимающие чаевые; под давлением можно уронить.

### 3.2 Клиенты

У каждого клиента: **заказ**, **терпение** (шкала), **настроение** (шкала), **состояние истории**, **набор примет**.

- **Терпение** тает от ожидания, пролитого, не того напитка; возвращается от верной подачи и от того, что его слушают.
- **Настроение** от раздражённого до восторженного; влияет на чаевые, качество сплетен и на то, начнёт ли драку или усмирит её.
- **Приметы** (язык тела): `thirsty` (хочет объём), `lonely` (хочет разговора), `hostile` (здесь за кем-то), `nervous` (владеет информацией), `fake` (играет роль). Навык Психологии показывает какая; без него — только анимация.
- **Слушание:** у клиента «на истории» можно вмешаться (налить) или остановиться и слушать. Прерывание пишет `ignored_<id>`, внимание — `heard_<id>`. Оба открывают и закрывают сцены дальше.

### 3.3 Шестое чувство / угроза

Функция оценки (`ULCThreatSensor`) ранжирует враждебность в зале. При высокой оценке:

- музыка притухает, гул разговоров падает (звуковая примета);
- с ветками Психологии/Крепких нервов в периферии подсвечивается опасный посадочный/посетитель;
- игрок может предупредить: успокаивающий напиток, вышибала к двери, проход перегорожен — или начать первым, если неизбежно.

### 3.4 Система «Коктейль-Комбо» (детально)

| Слой | Правило |
| :--- | :--- |
| Пословность | Основа → модификатор → акцент (задаётся данными для рецепта) |
| Скорость | У каждого налива окно расхода; вне его — падение качества |
| Непрерывность | Паузы > N секунд рвут комбо |
| Результат | качество ∈ {испорчено, нормально, хорошо, критично} → множители настроения/чаевых/опыта |

Считает `ULCRecipeLibrary` по выводу солвера — никогда по нажатиям кнопок (PHILOSOPHY §3.3).

## 4. Фаза 3 — Ночь (экшн/стелс)

Доступно по сюжетным флагам:

1. **Заказы «на вынос».** Бронированное окно открывается на фиксированное время; очередь бандитских заказов надо собрать быстро, пока снаружи растёт давление (таймер, стресс, чистое смешивание).
2. **Выборка долгов.** Проход через кварталы города (небольшие ручные уровни): найти должника, выбрать разговор / запугивание / забрать вещь. Оружие — барный инвентарь: бутылка, шейкер, сифон, поднос.
3. **Расследования.** Токены подслушанного, собранные на сменах, тратятся на разведку: кто с кем встречается, какая поставка, какой коп куплен. Разведка двигает арки фракций.

Правила ночного боя: редкие, смертельные, избегаемые. Стрелять можно; задуманные победы — деэскалация, побег или очень удачный бросок бутылки. Смерть = последствия («шум», репутация, дни в больнице), а не экран перезагрузки.

## 5. Системы

### 5.1 Древо навыков — четыре ветки

| Ветка | Эффект |
| :--- | :--- |
| **Флейринг** | Жонглирование, бросковые наливы: быстрее подача, больше чаевых, зрелище поднимает настроение; под давлением роняет. |
| **Психология** | Приметы, скрытые желания, распознавание вранья в диалоге; иконки намерений. |
| **Крепкие нервы** | Меньше тряски прицела/налива под огнём или паникой; ровнее струя, шире окна комбо. |
| **Алхимия** | «Особые ингредиенты»: снотворное, слабительное, яд — у каждого последствия для фракций и риск обнаружения. |

Опыт — с обслуженных клиентов, критических комбо, разруленных конфликтов и ночных целей. Навыки стоят XP + prerequisite.

### 5.2 Динамические события

Пул с весами, оценивается каждое утро по репутации фракций, «шуму» и номеру дня:

- **Обыск полиции:** уликам вешаются hide-теги; NPC-напарник прячет их, пока игрок проходит проверку на отвлечении. Провал = «шум» + штрафы, не game over.
- **Открытие конкурента / встреча группировки / визит знаменитости / отключение света:** каждое двигает толпу, заказы и музыку.

### 5.3 Разрушаемость и окружение

- Разбиваемые бутылки (оружие и опасность), летящие подносы, столы в укрытие.
- Сифон как огнетушитель / дымовая завеса; пролитый алкоголь + зажигалка = пожар (редко, эффектно).
- Бар помнит ущерб: починка стоит денег и выглядит иначе до ремонта.

### 5.4 Экономика и прогрессия

Стоки: товар, зарплаты, ремонты, улучшения, взятки. Лестница роста:

`забегаловка → отремонтированный бар → VIP-этаж → второй этаж → подпольное казино`

Каждый уровень: новая комната (планировка данными), новая толпа, новый риск, новый музыкальный сет. Уровень также кормит финал (см. [NARRATIVE.ru.md](NARRATIVE.ru.md)).

### 5.5 Мультиплеер (кооп 2–4)

| Роль | Работа |
| :--- | :--- |
| Бармен | Наливание, комбо, диалоги (весь одиночный цикл) |
| Официант | Носка, рассаживание, уборка, передача заказов |
| Вышибала | Дверь, угроза, контроль толпы, ночная охрана |
| Диджей | Музыкальный сет, настроение зала, подсказки событий |

- Listen server; один авторитет фаз (хост).
- Под нагрузкой роли естественно разъезжаются: бармен не рассаживает, вышибала не наливает — координация и есть дизайн.
- Провалы остаются социальными: плохая ночь стоит денег, но никогда не выкидывает игроков.
- Реконнект = зал ждёт; день не перезапускается.

## 6. Обучение и сложность

- Туториал 1-го дня диегетичен: тетрадь дяди (она же книга рецептов) учит наливу, слушанию и ночному окну.
- Слайдеры сложности: расход терпения, урон в бою, финансовое давление, помощь в прицеливании; «сюжетного режима», убирающего налив, нет (налив — это игра).
- Доступность: субтитры с именем говорящего, переназначаемые клавиши, смягчение тряски/вспышек, контрастные приметы.

## 8. Антицели

- Без live-service-сезонов и боевого пропуска (PHILOSOPHY §3.1).
- Без процедурной истории: рукописные биты, только взвешенные события.
- Без стрельбы как главного глагола: главный глагол — наливать.
