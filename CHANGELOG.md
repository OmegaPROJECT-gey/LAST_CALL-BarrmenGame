# Changelog

All notable changes to LAST CALL, in both languages. Sections are headed with the exact version from [VERSIONING.md](VERSIONING.md); the newest section is at the top. The Russian twin of every entry lives in [CHANGELOG.ru.md](CHANGELOG.ru.md).

## Unreleased

- Working rule (both languages): the AI agent never idles on background waits — while a file downloads, an archive unpacks or an engine installs, work continues on the next autonomous task; recorded in `docs/MAINTENANCE` §6, `ROADMAP` "How milestones are worked" and `CONTRIBUTING` PR rules.
- F0 in progress: UE 5.8 project skeleton (`LastCall.uproject`, `Source/` runtime + editor modules, phase clock `ULCPhaseManager`, noir renderer/input configs), design data with JSON Schemas, and three linters — `lc-data-lint`, `lc-dialogue-lint` (graph + EN/RU parity), `lc-docs-check` (twin links + link integrity) — running locally and in CI. Engine: official UE 5.8.3 Linux distribution unpacked to HDD (2026-10-13, verified `Engine/Binaries/Linux/UnrealEditor`). First project compile: module include paths fixed (module root on `PublicIncludePaths`), `BuildSettingsVersion.V7`, real engine header names corrected (`Engine/GameInstance.h`, `bStartPlayersAsSpectators`) — `LastCallEditor Linux Development` builds and links: `libUnrealEditor-LastCall.so` + `libUnrealEditor-LastCallTools.so` produced (2026-10-14). Open: Game target, Windows build.
- A1 groundwork: liquid data + core (`Data/Liquids/liquids.json` with schema and lint mapping; `Source/LastCall/Bar/LiquidCore`) — density-ordered strata with same-liquid merging, foam head with balance-tuned decay (`liquid.foam_decay_per_s`), overflow recorded as dated spill events, viscosity feeding the pour solver; 49 unit checks via `scripts/test-liquids.sh`. Open: UE glass material, spill decal and foam Niagara actors.
- A2 groundwork: the wall-of-recipes twist as data — `secret` block per recipe (fragment index, total, localization key, optional reveal flag) in `recipe.schema.json`, parsed by `RecipeLibraryCore`, assembled by `collect_secret_fragments()` with wall-integrity checks (duplicate fragment claims and disagreeing totals are refused); `signature_noir` carries fragment 1 of 13, its text lives in `Data/Localization/` EN+RU; 47 unit checks via `scripts/test-recipes.sh`. Open: UE `ULCRecipeLibrary` wrapper, more recipes as content grows.
- A3 groundwork: supplier data + economy core — `Data/Economy/suppliers.json` (cheap/standard/premium: price multiplier, per-morning stock limit, night risk, wares; schema + `lc-data-lint` mapping), `base_price` added to `Data/Liquids`, `economy.price_drift_amplitude` in `Data/Balance/core.json`; `Source/LastCall/Economy/EconomyCore` — deterministic daily price drift, unit price = base × supplier × drift, morning ledger refusing unlisted wares / stock overruns / uncovered totals; 36 unit checks via `scripts/test-economy.sh`, including a wares-vs-liquids cross-check. Open: ice and upgrades, loans/wages, the UE morning screen.
- A4 groundwork: engine-independent customer persona core (`Source/LastCall/Customers/CustomerCore`) — strict loading of `Data/Customers` (bilingual names, seat, schedule days/phases/hour, taste with substitutes, five tells with 0..1 baselines, faction, arc), tell reading rules (`tell_revealed`: Psychology 1 reads honest tells, only Psychology 2 exposes a performed `fake`), and the threat sensor without the engine — additive room score from hostile tells and low moods, capped at 1, banded calm/elevated/danger against `Data/Balance/core.json` "threat"; 51 unit checks via `scripts/test-customer-library.sh`. Open: the UE `ULCThreatSensor` and customer actor, animation-only reading, schedule-driven spawns.
- A5: social consequences - `Data/Factions/factions.json` registers the five factions (bilingual names, neutral start) and reaction tables mapping consequence flags to standing deltas - the Syndicate cools when you sit with a detective's case, the Room warms when you pour before promising, ignoring a guest costs Bureau and Room; no good/evil meter, only per-faction memory. Engine-independent `Source/LastCall/Social/SocialCore`: `FactionLibrary` (strict, unique flags, deltas cross-checked against the registry) + `StandingLedger` (each reaction fires once per flag across all days; `apply_log` feeds from the consequence log); 42 unit checks via `scripts/test-social.sh`. Open: the UE morning screen showing standing, save-persistence, new rows as arcs land.
- A7 groundwork: crafting - `Data/Crafting/crafting.json` rows (`infusion_coffee`, `syrup_orange`) whose outputs are ordinary `Data/Liquids` entries plus dumpable `swill`, so recipes can use crafted items as ingredients. Engine-independent `Source/LastCall/Crafting/CraftingCore`: `CraftLibrary` (strict: known kinds, positive inputs, strength 0..1, bilingual) + `attempt_craft` - distance from the row's time/strength decides clean / sloppy-but-usable / swill, failures never a dead end; tuning in `Data/Balance/core.json` "crafting"; three new liquid rows; 37 unit checks via `scripts/test-crafting.sh`. Open: the UE morning screen, crafted-variant recipe book, the signature questline.
- F0 hardening: `SaveStateCore` parses with `strtol`/`strtod` instead of `std::stoi`/`std::stod` — the Game target compiles with exceptions disabled (`-fno-exceptions`), and the save parser now refuses garbage without throwing (18 checks still green).
- F1 groundwork: engine-independent pour solver core (`Source/LastCall/Bar/PourSolverCore`) — tilt→flow curve (viscosity, saturation), glass fill/overflow/spill integration, combo quality from pour samples only; 27 unit checks via `scripts/test-pour-solver.sh`, wired into CI as the `solver` job. Open: UE wrapper, actors, Niagara stream, customer reaction (needs UE 5.8).
- F1 groundwork: engine-independent customer reaction core (`Source/LastCall/Customers/CustomerReactionCore`) — patience drain (idle/queue), spill shock window, burst walk-out, reaction bands (content/neutral/annoyed/shocked/walked-out), satisfaction per combo quality; 39 unit checks via `scripts/test-customer-reaction.sh`; shared test harness `tools/tests/test_support.h`; new tuning keys in `Data/Balance/core.json` ("customer"). Open: UE wrapper, barks, animations (needs UE 5.8).
- F2 groundwork: engine-independent phase clock core (`Source/LastCall/Core/DayScheduleCore`) — forward-only phase machine with skip-forward, timed (morning/summary) and untimed (shift/night) phases, day counter, save-boundary flag; 29 unit checks via `scripts/test-day-schedule.sh`; new tuning section in `Data/Balance/core.json` ("phases"). Open: UE wrapper, save system, placeholder content (needs UE 5.8).
- F2 groundwork: engine-independent save state core (`Source/LastCall/Core/SaveStateCore`) — versioned day-granular payload (day, phase, money, heat), deterministic serialization, strict parse (foreign version, missing/unknown fields and out-of-range values are refused); 18 unit checks via `scripts/test-save-state.sh`. Open: UE `ULCSaveSystem` wrapper over a SaveGame slot (needs UE 5.8).
- F3 groundwork: engine-independent order core (`Source/LastCall/Customers/OrderCore`) — order validity against the recipe library, serve outcomes (correct / substitute / wrong / wrong glass) with tip and mood effects, arrival schedules; engine-independent consequence log (`Source/LastCall/Core/ConsequenceLogCore`) — flags stamped with day and phase, deduplicated per day; 31 unit checks via `scripts/test-order.sh`; new tuning section in `Data/Balance/core.json` ("order"). Open: story beats, tell delivery, UE customer actor (needs UE 5.8).
- Infrastructure: minimal strict JSON reader (`Source/LastCall/Core/JsonCore`) — full JSON grammar, order-preserving objects, `\uXXXX` (incl. surrogate pairs) to UTF-8, byte-offset errors; lets every core load real `Data/` files without Unreal; 47 unit checks via `scripts/test-json.sh`, including a pass over `Data/Balance/core.json` itself.
- F1/A2 groundwork: engine-independent recipe library (`Source/LastCall/Bar/RecipeLibraryCore`) — strict loading of `Data/Recipes/*.json` (flow windows, layers, continuity, effects, story hook), conversion to the solver's `RecipeSpec`, duplicate-id and directory loading with error collection; 33 unit checks via `scripts/test-recipes.sh`, including an end-to-end pass "recipe file → solver → critical combo". Open: UE `ULCRecipeLibrary` wrapper (needs UE 5.8).
- F3/C1 groundwork: engine-independent dialogue runner (`Source/LastCall/Dialogue/DialogueRunnerCore`) — strict loading of `Data/Dialogue/*.json` through the shared JSON reader (nodes, choices, conditions on story flags / faction standing / skills, effects for flags, standing, mood, quests, `interrupt_recording`), walking the graph against a `DialogueWorld`, applying effects and routing mood/quest effects to the engine; graph integrity checks mirror the CI lint; 46 unit checks via `scripts/test-dialogue.sh`, driving the real `act1_harris_meeting.json` end to end. Open: UE `ULCDialogueRunner` widget/voice binding (needs UE 5.8).
- A6 groundwork: engine-independent skill tree core (`Source/LastCall/Core/SkillsCore`) — strict loading of `Data/Skills/skills.json` (four branches, requirements, costs, effect types), buy rules (requirements met, wallet covers cost, no re-buy, money deducted), effect aggregation (multipliers compose, ingredient unlocks union, reveals flip), plus a cross-check that dialogue skill conditions name real nodes; 41 unit checks via `scripts/test-skills.sh`. Open: UE skill panel UI, wiring multipliers into the pour/serve simulation.
