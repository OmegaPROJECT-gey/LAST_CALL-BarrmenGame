# Чейнджлог

Все значимые изменения LAST CALL на обоих языках. Разделы подписаны точной версией из [VERSIONING.ru.md](VERSIONING.ru.md); свежайший раздел — сверху. Этот файл — русский двойник [CHANGELOG.md](CHANGELOG.md), где записи ведутся на английском.

## Unreleased

- Рабочее правило (оба языка): AI-агент никогда не простаивает на фоновых ожиданиях — пока качается файл, распаковывается архив или ставится движок, работа продолжается по следующей автономной задаче; зафиксировано в `docs/MAINTENANCE.ru.md` §6, `ROADMAP.ru.md` («Как работают вехи») и правилах PR в `CONTRIBUTING.ru.md`.
- F0 в работе: скелет проекта UE 5.8 (`LastCall.uproject`, модули `Source/` runtime + editor, фазовые часы `ULCPhaseManager`, конфиги нуар-рендера/управления), дизайн-данные с JSON-схемами и три линтера — `lc-data-lint`, `lc-dialogue-lint` (граф + парность EN/RU), `lc-docs-check` (ссылки-двойники + целостность ссылок) — локально и в CI. Движок: официальный Linux-дистрибутив UE 5.8.3 распакован на HDD (13.10.2026, проверен `Engine/Binaries/Linux/UnrealEditor`). Первая сборка проекта: починены include-пути модуля (корень модуля в `PublicIncludePaths`), `BuildSettingsVersion.V7`, исправлены реальные имена движковых заголовков (`Engine/GameInstance.h`, `bStartPlayersAsSpectators`) — все ядра компилируются под clang; линковка в процессе.
- Заготовка F1: ядро солвера налива без зависимостей движка (`Source/LastCall/Bar/PourSolverCore`) — кривая наклон → расход (вязкость, насыщение), интеграция наполнения/перелива/разлива в стакан, качество комбо только из семплов налива; 27 юнит-проверок через `scripts/test-pour-solver.sh`, подключены к CI job'ом `solver`. Осталось: UE-обёртка, акторы, Niagara-струя, реакция клиента (нужно UE 5.8).
- Заготовка F1: ядро реакции клиента без зависимостей движка (`Source/LastCall/Customers/CustomerReactionCore`) — истощение терпения (ожидание/очередь), шок-окно от пролива, уход при большой луже, пороги реакций (content/neutral/annoyed/shocked/walked-out), удовлетворение по качеству комбо; 39 юнит-проверок через `scripts/test-customer-reaction.sh`; общий тестовый харнесс `tools/tests/test_support.h`; новые ключи тюнинга в `Data/Balance/core.json` (секция «customer»). Осталось: UE-обёртка, реплики, анимации (нужно UE 5.8).
- Заготовка F2: ядро фазовых часов без зависимостей движка (`Source/LastCall/Core/DayScheduleCore`) — машина фаз только вперёд с пропуском вперёд, таймлованные (утро/итог) и нетаймлованные (смена/ночь) фазы, счётчик дней, флаг границы сейва; 29 юнит-проверок через `scripts/test-day-schedule.sh`; новая секция тюнинга в `Data/Balance/core.json` («phases»). Осталось: UE-обёртка, save-система, плейсхолдер-контент (нужно UE 5.8).
- Заготовка F2: ядро состояния сейва без зависимостей движка (`Source/LastCall/Core/SaveStateCore`) — версионированный payload с гранулярностью по дням (день, фаза, деньги, heat), детерминированная сериализация, строгий парс (чужая версия, отсутствующие/неизвестные поля и значения вне диапазона отклоняются); 18 юнит-проверок через `scripts/test-save-state.sh`. Осталось: UE-обёртка `ULCSaveSystem` поверх слота SaveGame (нужно UE 5.8).
- Заготовка F3: ядро заказа без зависимостей движка (`Source/LastCall/Customers/OrderCore`) — проверка валидности заказа по библиотеке рецептов, исходы подачи (точный заказ / допустимая замена / не то / не тот бокал) с эффектами на чаевые и настроение, расписания прихода; ядро журнала последствий (`Source/LastCall/Core/ConsequenceLogCore`) — флаги со штампом дня и фазы, дедупликация по дням; 31 юнит-проверка через `scripts/test-order.sh`; новая секция тюнинга в `Data/Balance/core.json` («order»). Осталось: сюжетные биты, выдача примет, UE-актор клиента (нужно UE 5.8).
- Инфраструктура: минимальный строгий JSON-ридер (`Source/LastCall/Core/JsonCore`) — полная грамматика JSON, объекты с сохранением порядка, `\uXXXX` (включая суррогатные пары) в UTF-8, ошибки с байтовым смещением; позволяет ядрам читать реальные файлы из `Data/` без движка; 47 юнит-проверок через `scripts/test-json.sh`, включая проход по самому `Data/Balance/core.json`.
- Заготовка F1/A2: библиотека рецептов без зависимостей движка (`Source/LastCall/Bar/RecipeLibraryCore`) — строгая загрузка `Data/Recipes/*.json` (окна расхода, слои, непрерывность, эффекты, сюжетный крючок), конвертация в `RecipeSpec` солвера, отказ дубликатов id и загрузка каталога со сбором ошибок; 33 юнит-проверки через `scripts/test-recipes.sh`, включая сквозной проход «файл рецепта → солвер → критическое комбо». Осталось: UE-обёртка `ULCRecipeLibrary` (нужно UE 5.8).
- Заготовка F3/C1: раннер диалогов без зависимостей движка (`Source/LastCall/Dialogue/DialogueRunnerCore`) — строгая загрузка `Data/Dialogue/*.json` через общий JSON-ридер (узлы, выборы, условия по сюжетным флагам / стоянию фракций / скиллам, эффекты флагов, стояния, настроения, квестов, `interrupt_recording`), хождение по графу против состояния мира `DialogueWorld`, применение эффектов и передача эффектов настроения/квестов движку; проверки целостности графа зеркалят CI-линт; 46 юнит-проверок через `scripts/test-dialogue.sh` на реальном `act1_harris_meeting.json` от начала до конца. Осталось: UE-обёртка `ULCDialogueRunner` с виджетом и голосом (нужно UE 5.8).
- Заготовка A6: ядро древа навыков без зависимостей движка (`Source/LastCall/Core/SkillsCore`) — строгая загрузка `Data/Skills/skills.json` (четыре ветки, требования, цены, типы эффектов), правила покупки (требования выполнены, кошелёк покрывает цену, без повторной покупки, деньги списываются), агрегация эффектов (множители перемножаются, разблокировки ингредиентов объединяются, открытия знаний переключаются) и перекрёстная проверка, что скилл-условия диалогов называют реальные узлы; 41 юнит-проверка через `scripts/test-skills.sh`. Осталось: UE-панель навыков, подключение множителей к симуляции налива/подачи.
- Заготовка A1: данные жидкостей и ядро (`Data/Liquids/liquids.json` со схемой и маппингом линтера; `Source/LastCall/Bar/LiquidCore`) — страты, отсортированные по плотности, со слиянием одинаковых жидкостей, голова пены с баланс-скоростью распада (`liquid.foam_decay_per_s`), перелив, записанный как датированные события разлива, вязкость, питающая кривую расхода солвера; 49 юнит-проверок через `scripts/test-liquids.sh`. Осталось: UE-материал стакана, decal-разлив и Niagara-пена.
- Заготовка A2: твист «рецепты на стене» как данные — блок `secret` у каждого рецепта (номер фрагмента, всего, ключ локализации, опциональный флаг открытия) в `recipe.schema.json`, парсится `RecipeLibraryCore`, собирается `collect_secret_fragments()` с проверкой целостности стены (дубли фрагментов и разные «всего» отклоняются); `signature_noir` несёт фрагмент 1 из 13, его текст лежит в `Data/Localization/` на EN и RU; 47 юнит-проверок через `scripts/test-recipes.sh`. Осталось: UE-обёртка `ULCRecipeLibrary`, новые рецепты по мере роста контента.
