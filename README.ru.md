## Концепция

Ваш бар — это **швейцарский нож** города. Днём его заполняют офисные работники, вечером — криминал, а внизу — в секретном бункере с нелегальным оборудованием — настоящая работа начинается после закрытия.

Бар — это не просто место для выпивки. Это нейтральная территория для трёх группировок *и* тайный узел связи. Ваш дядя не просто умер: он был хранителем информации, которая может уничтожить город, — информации, **зашифрованной в рецептах коктейлей на стене**, нужной всем.

**Формула:** «Papers, Please» встречает «Grand Theft Auto» в декорациях безумной свадьбы. Игрок балансирует между искусством миксологии, криминальным миром и управлением бизнесом. Самый сильный навык — умение **вовремя наливать и вовремя слушать**.

## День из трёх фаз

| Фаза | Когда | Геймплей |
| :--- | :--- | :--- |
| **1. Подготовка** | Утро | Закупка продуктов, льда, алкоголя. Улучшение бара (ремонт кранов, новый миксер, VIP-зона). Крафт собственных настоек и сиропов: эксперименты, пока фирменный коктейль не станет визитной карточкой бара. |
| **2. Смена** | День / вечер | Физика жидкостей при наливании (наклоняете бутылку, контролируете струю), шкалы настроения и терпения клиентов, выслушивание их историй, чтение языка тела и разрядка драки до первого удара. |
| **3. Ночь** | После закрытия | Экшн/стелс: заказы «на вынос» через бронированное окно, выбивание долгов барным инвентарём, расследования по подслушанным разговорам. |

## Ключевые механики

- **Система «Коктейль-Комбо»** — смешивание в правильной последовательности с правильной скоростью даёт критический успех: клиент получает бафф настроения, вы — чаевые и опыт.
- **Древо навыков бармена** — Флейринг (жонглирование бутылками), Психология (видеть скрытые желания), Крепкие нервы (меньше тряски рук при перестрелке), Алхимия («особые ингредиенты»).
- **Динамические события** — в бар может ворваться полиция с обыском: прячьте нелегальный алкоголь или отвлекайте копов, пока NPC-напарник убирает улики.
- **Разрушаемость** — разбитая бутылка, опрокинутый стол, сифон как огнетушитель.
- **Кооператив на 2–4 игрока** — бармен, официант, вышибала, диджей: координируйтесь или тоньте в толпе.
- **Развитие бара** — от грязной забегаловки до элитного клуба в несколько этажей со своим подпольным казино.

## Технологии

| Слой | Решение |
| :--- | :--- |
| Движок | Unreal Engine 5 (Lumen GI, Nanite, Chaos) — [почему](docs/LANGUAGES.ru.md) |
| Геймплейный код | C++ (модули UE5), Blueprints для итераций |
| Физика жидкостей | Собственная симуляция налива (см. [ARCHITECTURE.ru.md](ARCHITECTURE.ru.md)) |

| Данные | UE DataTables, исходники JSON/YAML под контролем версий |
| Мультиплеер | Репликация UE, listen-server кооператив на 2–4 игрока |
| Документация | Markdown, двуязычно EN/RU, пересмотр по режиму из [docs/MAINTENANCE.ru.md](docs/MAINTENANCE.ru.md) |
| Бесплатные 3D-модели | Каталог с лицензиями: [docs/FREE-3D-MODELS.ru.md](docs/FREE-3D-MODELS.ru.md) |
